# KOKURO — اكتشف الأنمي

منصة ويب عربية لاكتشاف ومشاهدة الأنمي. تطبيق Flutter Web يعمل على المتصفح، مبني بفلسفة "الخصوصية أولاً": كل بياناتك (القائمة، المتابعة، الملف الشخصي) محفوظة محليًا على جهازك عبر `SharedPreferences`، من غير حساب و لا سيرفر.

## المميزات

- **اكتشف**: الصفحة الرئيسية تعرض اختيار اليوم، الموسم الحالي، توليداتك، والتوصيات — مُجمّعة من AniList و Kitsu و MyAnimeList (مع fallback تلقائي لو مصدر وقع).
- **ابحث**: بحث شامل عن الأنمي/الشخصيات/الأنواع مع سجل للعمليات الأخيرة (محلي).
- **مكتبتي**: قائمة مشاهدة محلية مع حالة المشاهدة (أشاهد / أنتهيت / أخطط / مسقطة) ومتابعة الحلقات.
- **صفحة العمل**: القصة المترجمة للعربية تلقائيًا، الشخصيات، الحلقات، المراجعات والتقييمات، والأعمال ذات الصلة.
- **المشغل**: تشغيل الحلقات مباشرة من يوتيوب داخل التطبيق مع تتبع تلقائي لتقدم المشاهدة.
- **بروفايل شخصي**: أفاتار، اسم، نبذة، ونوعك المفضل — محلي بالكامل.
- **واجهة عربية RTL** بالكامل بثيم داكن مخصص.

## التشغيل

```bash
flutter pub get
flutter run -d chrome
```

البناء للإنتاج:

```bash
flutter build web --release
```

ذكّر إن التطبيق بيشتغل كـ **PWA**: في المتصفح (Chrome/Edge) هتلاقي أيقونة "تثبيت" في شريط العناوين لتثبيته كتطبيق مستقل بقابلية تشغيل بدون إنترنت بعد أول تحميل.

## البنية

- `lib/kokuro/` — واجهة المستخدم والبلوك (Bloc).
- `lib/data/` — مصادر البيانات: AniList, Kitsu, MyAnimeList + بلوك التحكم المركزي.
- `web/` — غلاف الويب، manifest الـ PWA، service worker، واتصال YouTube API.

## مصادر البيانات

| المصدر | الاستخدام |
| --- | --- |
| AniList | البحث، التفاصيل، الشخصيات، التوصيات |
| Kitsu | الاستكشاف، ترجمة MAL id |
| MyAnimeList (Jikan) | إحصائيات، شخصيات احتياطية |

المصادر مترتبة بالسرعة: جرب AniList أولًا، فـ Kitsu، وأخيرًا Jikan (اللي بيواجه بطء ودائمًا بيتابعه breaker تلقائي).

## الملاحظات

- جميع البيانات الشخصية محلية ولا تُرسل لأي خادم خارجي.
- وضع "بدون حساب" — لا يوجد تسجيل دخول بالتصميم.
